## What Was Done

- Memory research with six agents: the demo board's flash is on the RP2350's private bus (netlist-traced,
  unreachable); the RP2 SPI-RAM emulation is 3 to 8x slower and unported to the RP2350 board; the QSPI Pmod
  is the memory. Streaming fetch measured at +114 cells (67.0% of the tile). `scratch_pad/2026-09-04_sep/03_memory_options/`.
- `designs/ttsky26c-arm16` created from the TinyTapeout template with a fresh history; lab work promoted;
  `tt/` cloned at `d65690e` and ignored; remote set to github.com/moein-maleki/ttsky26c-arm16, never pushed.
- Decoder audit: branch offsets unshifted from PC+4, direction bit ignored, BL without link, r15 absent,
  N and V read bit 31, carry inverted on subtraction (confirmed by simulation, all eight vectors mismatch).
  `scratch_pad/2026-09-04_sep/04_spec/REPORT.md`.
- Cache question measured: flop caches 14% of the tile for 4 lines, about 400% for 128 instructions; the core
  is 65,780 um^2 on SG13G2 (2.01x sky130); IHP's 256x16 macro exists, ttihp26b is full. `05_cache_question/`.
- VGA blocks measured: timing 1.8%, four-digit renderer 5.2%, 8x8 bitmap 9.8%. `06_vga_question/`.
- Spec written and revised to v0.3: v0.1 (2026-09-04), v0.2 TinyVGA replaces the digit with the UART behind
  the mode switch (09-05), v0.3 stall policy, forwarding live only in ROM mode, ROM above UART (09-06).
- Architecture exploration with a cycle model and four agent reports: drain policy mandatory (30% on loops
  and loads), forwarding is decoration on the streamed path, branch prediction not worth a gate, no parallel
  memory on this pin budget, latch caches 6 to 12%, tnt's register file 22% of the tile, ROM macro 1.51
  bits/um^2. `scratch_pad/2026-09-06_sep/01_architecture_exploration/REPORT.md`.
- The lab repository marked archive (`sandbox/computer-architecture-lab` at `af1a532`).

## Key Decisions

- TTSKY26c with the spec, not 26d or IHP — the user's call, twice, against the recommendation; the held tile
  and the March 2027 chips outweighed the risk for them.
- QSPI Pmod, flash for code and PSRAM A for data, no volatile chip mode — the only memory the ASIC can reach,
  and a cold-boot protocol keeps the demo host-free.
- TinyVGA four-digit renderer instead of the digit, UART behind the mode switch, clock fixed at 25 MHz —
  a better demo for 5.2% of the tile; the pixel clock removes the 20 MHz fallback.
- No cache on sky130; the SRAM cache is the IHP follow-on — measured, not estimated.
- Drain stall policy, valid/ready fetch, 0b1111 bubbles — the probe has no policy and freeze costs 30%.
- The internal ROM outranks the UART — proof of life with nothing on the socket, and the only mode at one
  instruction per cycle where forwarding is visible.
- Standard ARM encoding, ALU flags rewritten from the ARM definition, general registers not reset — so a
  standard assembler's output runs, and the golden model, not the lab RTL, is the reference.
